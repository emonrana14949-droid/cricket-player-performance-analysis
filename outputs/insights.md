# Key Insights — Cricket Player Performance Analysis

> This project uses synthetic practice data generated with NumPy. The player names are real Bangladesh cricketers, but all numbers are made up for practice — they are not real match statistics.

- Dataset size: **360 innings** across **7 players**.
- Highest batting average: **Mushfiqur Rahim** (46.88).
- Highest average strike rate (players with 30+ innings): **Towhid Hridoy** (100.00).
- Most centuries: **Tamim Iqbal** (1 century).
- Most total runs: **Litton Das** (2281 runs in 69 innings).
- Best opponent to bat against (highest average runs): **Pakistan** (40.10 average runs per innings).
